# 새 Task 생성 요청

아래 양식을 채워 새 task 생성을 요청합니다.

에이전트는 요청을 받으면 다음 순서로 처리합니다.

- `Docs/PLANS.md`에서 이전 단계와 현재 상태를 확인합니다.
- 요청이 다음 순서로 오기에 적합하면 작업리스트 단계 하나를 확정하고 `Tasks/`에 task 문서를 생성합니다.
- 이전 task 다음 순서로 적합하지 않거나 한 task로 다루기에는 범위가 너무 크면 진행하지 않고 이유와 분할안을 먼저 설명합니다.
- 이 단계에서는 task 문서만 작성하며 구현을 시작하지 않습니다.
- 시나리오 내용은 `Docs/GDD_v1.3_에테르나.md` §6을 근거로 합니다. GDD에 없는 제목, 업무, 수첩 규칙, 이상 현상, 연출은 임의로 만들지 않습니다.
- GDD §10 `결정 대기` 항목에 걸리는 요청이면 결정이 필요함을 먼저 알리고 task 문서를 만들지 않습니다.

## 요청 양식

### 원하는 결과

- [이번 task에서 사람이 확인할 수 있어야 하는 핵심 결과]

### 적용 범위

- 공통 시스템 / 시나리오 ID(S01~S03):
- 관련 게임 내 시각·이벤트 (예: 01:44, 03:03, 04:44 / 없으면 `해당 없음`):
- 주요 구역 (예: `Sub_GrandHall`, `Sub_UtilityRoom`):

### 세부 설명

- [필요한 동작과 사용자 의도]
- [반드시 지켜야 하는 규칙 또는 제공된 기획 내용]

### 이미 존재하는 요소

- [확인된 코드, Blueprint, 맵, 입력, UI, 데이터 이름]
- [없거나 모르면 `확인 필요`]

### 범위 밖

- [이번 task에서 다루지 않을 것]

### 기대하는 결과 확인

- [사용자가 Unreal Editor 또는 PIE에서 확인하고 싶은 결과]
