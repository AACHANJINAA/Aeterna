# Q1. 「인수인계」 — 튜토리얼 시나리오

| 항목 | 내용 |
|---|---|
| 게임 내 시간 | 02:00 ~ 02:30 |
| 예상 플레이 시간 | 5~7분 |
| 목적 | 기본 조작(이동/상호작용/손전등/수첩/시계) 학습 + 박물관 전체 동선 1회 학습 |
| 실패 조건 | 없음 (안전 구간) |
| 롤백 지점 | 없음 |
| 사용 구역 | 경비실 → 중앙 대홀 → 아치 복도 → 전시 케이스 회랑 |
| 해금 요소 | 손전등, 수첩, 손목시계, 순찰 단말기 |

---

## 1. 시놉시스

첫 출근한 야간 경비원(플레이어)이 경비실에서 눈을 뜬다. 전임 경비원은 없다.
책상 위에 남겨진 것은 손전등, 낡은 수첩, 그리고 "먼저 퇴근합니다"라는 쪽지뿐.
플레이어는 수첩의 지시에 따라 1층 순찰 체크포인트 3곳을 돌며 박물관의 구조를 익힌다.
마지막 체크포인트 근처에서 **비어 있는 전시 케이스**를 발견한다. (Q4 복선)

---

## 2. 씬 플로우

### STEP 0 — 오프닝 (02:00)

- 페이드 인. 1인칭. 경비실 책상 앞 의자에 앉아 있는 상태에서 시작
- 화면 흐릿 → 또렷 (졸다 깬 연출). 벽시계 소리 `tick-tock` 루프
- 시선을 책상으로 내리면 다음 오브젝트가 보임:
  - **쪽지** (읽기 가능)
  - **손전등** (획득 가능)
  - **수첩** (획득 가능)
  - **손목시계** (획득 가능)
  - 순찰 단말기 (획득 가능, 체크포인트 스캔용)

> **쪽지 텍스트**
> ```
> 신입 씨에게.
> 미안하지만 먼저 갑니다. 인수인계는 수첩에 다 적어뒀어요.
> 수첩에 적힌 것만 지키면 아무 일도 없습니다.
> "만"이 아니라 "은" 입니다. 반드시.
> — 前 야간 경비 (이름은 지워져 있다)
> ```

**튜토리얼 프롬프트 (순서 강제)**
1. `[E] 쪽지 읽기` → 읽으면 다음 단계 활성화
2. `[E] 손전등 획득` → `[F] 손전등 켜기/끄기` 안내
3. `[E] 수첩 획득` → `[Tab] 수첩 펼치기` 안내
4. `[E] 손목시계 획득` → `[T] 시계 확인` 안내 (왼손을 들어 올리는 애니메이션, 확인 중 시야 하단 가림)
5. `[E] 순찰 단말기 획득` → 획득 시 Q1 목표 갱신

### STEP 1 — 수첩 첫 페이지 (튜토리얼 규칙 노출)

수첩을 처음 펼치면 1~2페이지가 강제 표시된다.

> **수첩 p.1 — 「기본 수칙」**
> ```
> 하나. 근무 시간은 02:00 ~ 05:00. 05:00 전에는 절대 밖으로 나가지 마시오.
> 둘.   손전등 배터리는 아껴 쓰시오. 어둠보다 무서운 것은 방전입니다.
> 셋.   순찰은 "일"입니다. 일을 하지 않으면, 저쪽도 일을 시작합니다.
> ```

> **수첩 p.2 — 「오늘의 업무 ①」**
> ```
> 1층 순찰 체크포인트 3곳을 단말기로 스캔할 것.
>   A. 중앙 대홀 — 티라노 전시대 옆 기둥
>   B. 아치 복도 — 복도 끝 'ONE WAY' 표지판 아래
>   C. 전시 회랑 — 7번 진열장 맞은편 벽
> 순서는 상관없음. 단, 02:30 전에 끝낼 것.
> ```

- HUD 없음. 목표는 수첩에만 표시 (다이어제틱 UI 원칙)
- 02:30까지 못 끝내도 실패는 아니지만, 02:30에 Q2 무전이 오면서 자연스럽게 다음 퀘스트로 전환

### STEP 2 — 체크포인트 A: 중앙 대홀

- 경비실 문을 열면 **완전한 어둠**. 손전등 필수 (F키 안내 재노출)
- 대홀 진입 시 스크립트 연출:
  - 손전등 빛이 티라노 골격을 아래에서 위로 훑는 카메라 유도 (라이트 셰이프로 시선 유도)
  - 티라노는 **움직이지 않는다**. Q1에서는 순수하게 "멋있고 으스스한 배경"
- 기둥의 체크포인트 단말 포트에 `[E] 스캔` → "체크 완료 (1/3)" 사운드 `beep`
- 스캔 직후 이벤트: **머리 위 샹들리에 하나가 깜빡** (전력 이상 복선 → Q2 연결)

### STEP 3 — 체크포인트 B: 아치 복도

- 복도는 벽 포스터(공룡 뼈 그림)가 늘어선 구간
- 조명이 절반만 살아 있음: 복도 중간부터 **완전 소등 구역** (Q2에서 수리할 배전반 관할)
- 'ONE WAY' 표지판 아래 스캔 → "체크 완료 (2/3)"
- 연출: 스캔 순간 복도 끝(어둠 속)에서 아주 작은 `달그락` 소리 1회. 손전등을 비추면 아무것도 없음
  - **중요: Q1에서는 어떤 실체도 등장시키지 않는다.** 소리만. 공포는 후불제.

### STEP 4 — 체크포인트 C: 전시 회랑 + 복선

- 회랑의 진열장들을 지나며 이동. 진열장 몇 개는 `[E] 살펴보기`로 전시물 설명 팝업 (수집 도감의 기초, 선택 요소)
- **7번 진열장: 유리는 멀쩡한데 내부가 비어 있음.** 받침대 위 명패만 남음
  - 명패: `"수각류 공룡 앞발 골격 — 백악기 후기"` (Q4에서 찾을 뼈)
  - `[E] 살펴보기` 시 플레이어 독백: *"...원래 비어 있던 건가?"*
  - 이 상호작용은 **선택**이지만, 했을 경우 Q4에서 대사 분기 (복선 회수 강화)
- 맞은편 벽 스캔 → "체크 완료 (3/3)"

### STEP 5 — 복귀 및 클리어 (≤ 02:30)

- 3곳 스캔 완료 시 수첩에 자동으로 체크 표시가 그어짐 (연필 소리 SFX)
- 경비실로 돌아오는 길에 **무전기 노이즈**가 잡히기 시작 → 경비실 도착 시 Q2 무전 이벤트로 연결
- Q1 완료 = **체크포인트 세이브 #1** 기록

# Q2. 「소등 점검」 — 손전등 · 전력 메커닉 시나리오

| 항목 | 내용 |
|---|---|
| 게임 내 시간 | 02:30 ~ 03:00 |
| 예상 플레이 시간 | 6~8분 |
| 목적 | 배터리 자원 관리 학습 + 전력(두꺼비집) 시스템 도입 + "규칙" 시스템 첫 체험 |
| 실패 조건 | 없음 (심리적 압박만 존재, 실해 없음) |
| 롤백 지점 | 없음 |
| 사용 구역 | 경비실 → 아치 복도(소등 구역) → 배전실 |
| 해금 요소 | 배터리 파밍, 전력 복구 시스템, 규칙 발동 연출 |

---

## 1. 시놉시스

02:30, 무전기에서 본부의 지시가 온다. "복도 구역 전원이 나갔다. 배전반을 올려라."
플레이어는 손전등 하나에 의지해 완전히 어두운 아치 복도를 통과해 배전실에 도달해야 한다.
전원을 복구하면 복도가 밝아지지만 — 수첩의 규칙 하나가 그때부터 발동한다.
**「불이 켜진 복도의 포스터 속 뼈 그림은 조금씩 움직인다. 신경 쓰지 마시오. 세지도 마시오.」**

> **디자인 의도**: 이 퀘스트에서 플레이어를 해치는 것은 아무것도 없다.
> 목적은 ① 배터리 관리 습관 형성 ② "밝음 ≠ 안전"이라는 이 게임의 문법 각인
> ③ 규칙을 읽고 → 상황에서 떠올리고 → 지키는 루프의 무해한 첫 반복 연습.

---

## 2. 씬 플로우

### STEP 0 — 무전 (02:30, Q1 완료 직후)

경비실 무전기가 울린다. `[E] 응답`

> **무전 대사**
> ```
> 본부: ...지지직... 경비원님, 들리십니까. 복도 구역 배전이 내려갔습니다.
>       B구역 끝 배전실에서 메인 차단기 올려주세요.
> 본부: 아, 그리고 — 배전실 열쇠는 전임자가 어디 뒀는지 모르겠네요.
>       경비실 어딘가에 있을 겁니다. ...지직...
> ```

**서브 목표 ①: 배전실 열쇠 찾기 (경비실 내 미니 탐색)**
- 열쇠 위치: 캐비닛 서랍 2번째 칸 (열쇠걸이에는 없음 — 걸이엔 빈 고리와 먼지 자국만)
- 탐색 중 발견물 (선택 파밍):
  - **배터리 ×1** (책상 서랍)
  - **커피 얼룩 묻은 근무일지** — 읽기 가능. 마지막 장: 날짜가 어제인데 필체가 점점 흐트러지다 문장이 끊겨 있음 (세계관 텍스트, 스토리 복선)

### STEP 1 — 수첩 갱신 (규칙 사전 노출)

열쇠 획득 시 수첩이 자동으로 펄럭이며 새 페이지가 표시된다. (연출: 바람 없는데 넘어감)

> **수첩 p.3 — 「복도에 관하여」**
> ```
> 복도의 불을 켜기 전에 알아두시오.
>
> 하나. 불이 켜진 동안, 벽에 걸린 포스터 속 뼈 그림은 조금씩 움직입니다.
>       정상입니다. 신경 쓰지 마시오.
> 둘.   그림 속 뼈의 개수를 세지 마시오.
>       세기 시작하면 개수가 매번 다르다는 걸 알게 되고,
>       그걸 알게 되면 그쪽도 당신이 알았다는 걸 알게 됩니다.
> 셋.   포스터가 "떨어져 있다면", 주워서 다시 걸어 주시오. 뒤집지 말고.
> ```

- 규칙 셋은 이번 퀘스트에서 실제로 1회 발생 (STEP 4)
- 규칙 둘은 시스템적으로 "포스터를 3초 이상 응시하면 카운트 UI가 저절로 뜨려는" 페이크 연출로 구현 가능 (아래 구현 노트)

### STEP 2 — 소등 복도 진입 (배터리 압박 구간)

- 복도 진입부부터 **완전 암흑**. 손전등 없이는 한 치 앞도 안 보임
- 이 구간부터 배터리 소모율 100% 적용. HUD 게이지 없음 — 배터리가 20% 이하로 떨어지면 **손전등 빛이 노랗게 변하고 깜빡임** (다이어제틱 경고)
- 배터리 파밍 포인트 2곳:
  - 복도 중간 벤치 아래 (손전등을 아래로 비춰야 보임 — "빛을 어디에 비추는가"를 가르침)
  - 배전실 앞 분실물 상자
- 앰비언스: 자기 발소리의 잔향이 과장되게 울림. 가끔 발소리 잔향이 **반 박자 늦게 하나 더** 들림 (실체 없음, 사운드만)

### STEP 3 — 배전실 (전력 복구 인터랙션)

- `[E] 열쇠로 문 열기` → 좁은 배전실. 벽에 메인 차단기 + 구역별 스위치 6개
- **인터랙션 퍼즐 (간단)**: 메인 차단기를 바로 올리면 `퍽` 하고 다시 내려감
  → 구역 스위치 6개를 전부 OFF로 내린 뒤 → 메인 ON → 구역 스위치를 하나씩 올리는 순서
  (실제 두꺼비집 복구 절차. 튜토리얼 팁 쪽지가 배전반 옆에 붙어 있음)
- 구역 스위치를 하나 올릴 때마다 복도 조명이 **구간별로 순차 점등**되는 것이 배전실 문틈으로 보임 + 멀리서 `퉁... 퉁...` 점등음
- 마지막 스위치를 올리는 순간, 복도 쪽에서 **종이가 바닥에 떨어지는 소리** 1회

### STEP 4 — 밝아진 복도 귀환 (규칙 발동 구간)

이 퀘스트의 핵심 시퀀스. 돌아가는 길, 복도는 이제 환하다. 그러나:

1. **포스터 미세 변화**: 갈 때 봤던 포스터들과 뼈 그림의 포즈가 미묘하게 다름
   - 구현: 포스터 머티리얼을 텍스처 2~3장 세트로 만들고, 플레이어가 등을 돌린 사이(시야 밖일 때)에만 스왑
   - **플레이어가 보는 동안에는 절대 바뀌지 않는다** — "내가 잘못 봤나?" 하는 불확실성이 목표
2. **떨어진 포스터 1장**: STEP 3에서 소리 났던 그 포스터가 바닥에 떨어져 있음
   - `[E] 주워서 걸기` → 수첩 규칙 셋 이행. 걸면 낮은 안도 앰비언스
   - 선택지 아님. 뒤집어 거는 인터랙션은 존재하지 않음 — 다만 줍는 순간 뒷면이 0.5초 슬쩍 보이는데, **뒷면에 연필로 그은 正자 표시가 가득함** (누군가 세고 있었다 — 규칙 둘의 복선)
   - 그냥 지나칠 수도 있음. 지나치면 Q3 시작 전 무전에서 "복도 정리 상태 확인 바랍니다" 한 줄 추가 (소프트 리마인드, 페널티 없음)
3. **세지 마시오 페이크**: 포스터 하나를 3초 이상 정면 응시하면, 화면 구석에 반투명한 카운터 `1... 2... 3...`이 저절로 올라가기 시작 → 시선을 떼면 즉시 사라짐
   - 플레이어가 "세는" 행동을 시스템이 대신 시작해버리는 연출. 실해 없음. 4초 이상 유지 시 카운터 숫자가 갑자기 `?`로 바뀌고 짧은 이명 SFX 후 종료

## 5. 구현 노트 (프로그래머용)

- **포스터 스왑**: 각 포스터에 `WasSeenThisFrame` 플래그. 플레이어 시야 프러스텀 + 가림(occlusion) 체크 통과 시 true. **false인 프레임에서만** 텍스처 인덱스 변경 허용. 변경 쿨다운 20~40초 랜덤
- **응시 카운터 페이크**: 카메라 → 포스터 Dot Product > 0.95 && 거리 < 600 유지 시간 측정. 3초 도달 시 UMG 카운터 위젯 페이드 인. 시선 이탈 즉시 제거
- **배전반 퍼즐**: 상태 머신 `AllZonesOff → MainOn → Zone1..6 순차`. 순서 틀리면 메인 트립(내려감) + SFX, 리셋
- **배터리 소모**: `FlashlightComponent`에서 초당 소모, 강/약/UV 배율 1.0 / 0.5 / 3.0 (UV는 Q4 해금이므로 Q2에선 비활성)
- **사운드 잔향 발소리**: 플레이어 발소리 이벤트를 0.4~0.6초 딜레이 + 저역 필터로 1회 복제 재생, 확률 15%
