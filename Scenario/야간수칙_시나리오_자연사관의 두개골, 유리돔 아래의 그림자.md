# 야간 수칙 선정 시나리오 2개 최종본

## 개요

기존 기획의 핵심 구조인 **박물관 야간 경비, 전임 경비원의 수첩, 손전등, 이상 현상, 규칙 충돌**을 유지한 상태에서 추가할 시나리오 2개다.

두 시나리오는 새벽 5시 전까지 발생하는 이상 현상으로 배치한다.

| 번호 | 시나리오 | 배치 시간 | 역할 |
|---|---|---|---|
| 1 | 자연사관의 두개골 | 03:20~03:40 | 수칙을 지키는 플레이 긴장감 |
| 2 | 유리돔 아래의 그림자 | 04:40~05:00 | 후반부 서사 암시와 여운 |

---

## 1. 자연사관의 두개골

### 배치 시간

03:20~03:40

### 장소

자연사관 또는 중앙 홀 안쪽의 공룡 두개골 전시 구역.

### 시나리오 역할

플레이어가 수첩 규칙을 지키며 전시물의 반응을 피해야 하는 메인 플레이 시나리오다.  
손전등 사용, 움직임 제한, 소음 관리가 핵심이다.

### 평범한 업무

플레이어는 자연사관의 센서 박스를 재부팅해야 한다.

- 자연사관 순찰 체크포인트 확인
- 공룡 두개골 전시대 아래 센서 박스 재부팅
- 배전반 퓨즈 상태 확인

센서 박스는 공룡 두개골 전시대 아래에 있어, 플레이어가 위험 구역으로 직접 들어가야 한다.

### 수첩 규칙

```text
두개골의 입이 열려 있다면, 그 안을 비추지 마시오.

뼈가 삐걱거리는 소리를 내면 움직이지 마시오.

전시대 아래에서는 기계음을 내지 마시오. 팔을 움직이는 소리도 들립니다.
```

### 이상 현상

플레이어가 자연사관에 도착하면 공룡 두개골의 입이 살짝 열려 있다.  
두개골은 빛과 소리에 반응한다.

로봇 팔로 센서 박스를 조작할 때마다 작은 모터음이 발생하고, 이 소음이 쌓이면 두개골이 점점 반응한다.

### 플레이 흐름

1. 자연사관에 진입한다.
2. 수첩 규칙을 확인한다.
3. 두개골 입 안을 비추지 않도록 손전등 방향을 조심한다.
4. 전시대 아래 센서 박스에 접근한다.
5. 로봇 팔로 센서 박스를 조작한다.
6. 뼈가 삐걱거리는 소리가 나면 즉시 멈춘다.
7. 소음이 가라앉으면 다시 조작한다.
8. 센서 박스 재부팅 후 자연사관을 빠져나간다.

### 주요 판정

| 행동 | 결과 |
|---|---|
| 걷기 | 소음 소량 증가 |
| 뛰기 | 소음 크게 증가 |
| 로봇 팔 조작 | 소음 증가 |
| 멈춰 있기 | 소음 감소 |
| 두개골 입 안을 비춤 | 위험 단계 상승 |
| 삐걱거리는 소리 중 움직임 | 위험 단계 상승 |

### 두개골 반응 단계

| 단계 | 상태 | 연출 |
|---|---|---|
| 1단계 | 경고 | 뼈가 작게 삐걱거림 |
| 2단계 | 위험 | 두개골 턱이 더 벌어짐 |
| 3단계 | 실패 직전 | 조명이 깜빡이고 뼈 부딪히는 소리가 가까워짐 |
| 4단계 | 실패 | 전시관 암전 또는 시작 위치로 되돌아감 |

### 실패 조건

- 소음 게이지가 최대치에 도달
- 손전등을 두개골 입 안에 일정 시간 이상 비춤
- 삐걱거리는 소리가 나는 동안 계속 움직임

### 기존 기획과의 연결

이 시나리오는 기존 기획의 다음 요소를 그대로 활용한다.

- 평범한 야간 순찰 업무
- 전임 경비원의 수첩 규칙
- 손전등 사용 판단
- 전시물 반응
- 배전반/센서 점검
- 규칙을 지켜야 살아남는 긴장감

### 게임을 풍부하게 만드는 요소

- 플레이어가 움직일지 멈출지 계속 판단하게 만든다.
- 손전등이 단순 조명이 아니라 위험 요소가 된다.
- 로봇 팔 조작이 실제 플레이와 연결된다.
- 공룡 두개골이라는 강한 오브젝트로 기억에 남는 장면을 만들 수 있다.

## 2. 유리돔 아래의 그림자

### 배치 시간

04:40~05:00

### 장소

유리 천장과 샹들리에가 있는 돔 홀 또는 중앙 홀 상층부.

### 시나리오 역할

근무 종료 직전 발생하는 후반부 이상 현상이다.  
빛과 그림자를 이용해 로봇 플레이어의 정체와 서사를 암시한다.

### 평범한 업무

플레이어는 근무 종료 전 마지막 조명 장치를 점검한다.

- 비상등 복구
- 중앙 조명 장치 리셋
- 마지막 순찰 체크포인트 확인

조명 장치를 리셋하는 순간, 플레이어의 그림자가 비정상적으로 보이기 시작한다.

### 수첩 규칙

```text
그림자가 당신보다 먼저 움직이면 그 자리에 멈추시오.

로봇의 그림자가 사람처럼 보이면 불을 끄지 마시오.

사람의 그림자가 당신을 돌아보면, 그것은 아직 당신을 용서하지 않았습니다.
```

### 이상 현상

조명 장치를 리셋하면 유리돔 위로 새벽빛 또는 강한 조명이 들어온다.

처음에는 로봇 형태의 그림자가 보인다.  
하지만 조명이 흔들릴수록 벽이나 바닥에 비친 그림자가 사람 형태로 바뀐다.

화면에는 로봇 팔이 보이지만, 그림자는 인간처럼 보인다.

### 플레이 흐름

1. 유리돔 홀에 진입한다.
2. 마지막 순찰 체크포인트를 확인한다.
3. 중앙 조명 장치를 리셋한다.
4. 벽과 바닥에 비친 그림자를 확인한다.
5. 그림자가 먼저 움직이면 멈춘다.
6. 그림자가 사람처럼 보이면 조명을 끄지 않는다.
7. UV 모드로 벽을 비춘다.
8. 숨겨진 문장을 확인한다.
9. 05:00 근무 종료 알림과 함께 시나리오가 종료된다.

### 주요 판정

| 상황 | 플레이어 행동 |
|---|---|
| 그림자가 먼저 움직임 | 움직이지 않고 멈춤 |
| 그림자가 사람처럼 변함 | 조명을 끄지 않음 |
| 그림자가 돌아보려 함 | UV 모드로 벽 확인 |
| 숨겨진 문장 발견 | 기억 단서 획득 |

### 그림자 변화 단계

| 단계 | 그림자 상태 |
|---|---|
| 1단계 | 로봇 형태 그림자 |
| 2단계 | 팔만 인간처럼 보임 |
| 3단계 | 전체가 사람 형태에 가까워짐 |
| 4단계 | 그림자가 플레이어를 돌아보려 함 |

### 숨겨진 문장

UV 모드로 벽을 비추면 다음 문장이 보인다.

```text
나는 죽었지만, 내가 느낀 것들은 삭제되지 않았다.
```

### 실패 조건

- 그림자가 먼저 움직이는 중 플레이어가 움직임
- 사람 그림자가 나온 상태에서 조명을 꺼버림
- 그림자가 완전히 돌아볼 때까지 아무 행동도 하지 않음

### 기존 기획과의 연결

이 시나리오는 기존 기획의 다음 요소를 활용한다.

- 손전등과 빛 시스템
- UV 모드
- 전원 복구와 조명 장치
- 새벽 시간대의 불안감
- 수첩 규칙을 통한 행동 제한
- 다이어제틱한 정보 전달

### 게임을 풍부하게 만드는 요소

- 괴물이 직접 등장하지 않아도 심리적 공포를 만들 수 있다.
- 빛과 그림자를 이용해 후반부에 강한 여운을 준다.
- 로봇 플레이어의 정체를 직접 설명하지 않고 시각적으로 암시한다.
- 새벽 5시 직전의 마지막 이상 현상으로 사용하기 좋다.

## 플레이어 서사 핵심

플레이어는 1인칭 시점의 로봇 경비원이다.  
하지만 완전히 새로 만들어진 기계가 아니라, 과거 실존했던 인간의 데이터가 기반이 된 존재다.

### 원본 인간

- 평범한 삶을 살던 사람이었다.
- 직업은 군인이었다.
- 전투에서 뛰어난 활약을 했다.
- 마지막 전투에서 사망했다.
- 사망 전 남은 전투 기록, 행동 패턴, 감정 반응이 로봇에 복제되었다.

### 남아 있는 감정

원본 인간에게 남은 감정은 하나로 단정되지 않는다.

- 좋은 추억
- 힘든 기억
- 그리움
- 두려움
- 후회 없음
- 앞으로의 삶을 기대하던 마음

게임 안에서는 이 서사를 길게 설명하지 않는다.  
로봇 팔의 떨림, 시스템 로그, 그림자, UV 문장 같은 짧은 단서로만 암시한다.

## 팀원 공유용 핵심 정리

두 시나리오는 기존 기획을 바꾸는 것이 아니라, 기존의 야간 수칙 구조 안에 들어가는 이상 현상이다.

`자연사관의 두개골`은 손전등, 움직임, 소음 관리로 플레이 긴장감을 만든다.  
`유리돔 아래의 그림자`는 빛과 그림자를 통해 로봇 플레이어의 서사를 암시한다.

하나는 게임성, 하나는 후반부 서사와 여운을 담당한다.
