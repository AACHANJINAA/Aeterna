## 1. 흐름 골격

밤2는 밤1 같은 선형 상태머신이 아니다. **업무(뼈 3개)는 자유 순서**이고, 그 위에 **상시 판정 3종**(규칙 2·3·4)이 병렬로 돈다.

```
[Boot] → [Briefing] → [Work(자유 진행)] ── 뼈 3/3 설치 → [Complete]
                          │
                          ├─ 상시: 눈구멍 응시 판정 (§6-1)
                          ├─ 상시: 화석 소실 판정 (§6-2)
                          └─ 매시 44분: 목격 판정 (§6-3)
                          └─ 위반 → [Failure] → 밤 재시작
```

| 상태 | 내용 |
|---|---|
| `Boot` | 부팅 시퀀스 (밤1과 동일 규격). 경비실 재기동 |
| `Briefing` | **「오늘의 업무」 두루마리 위젯** 자동 표시 (밤2 최초 도입 — SPEC_NIGHT1 §3-0 결정): *"오늘의 업무 — 1층 전시관 점검"* + 규칙 4개. `[확인]`으로 닫음. 닫기 전 이동 잠금 `[제안]`. 이후 `Tab` 수첩에서 상시 재열람 |
| `Work` | 클럭 시작. 뼈 3개 회수·설치 자유 진행. 판정 3종 활성 |
| `Complete` | 마지막 뼈 설치 지점에서 종료 시퀀스 (§9) |
| `Failure` | FailureSystem 위임 (§8) |

- `[확정]` 규칙 4개는 밤 시작 시 수첩에 이미 기재되어 있다 (PDF 기준). 안내 데스크 스캔 의존 없음 — v1.3의 "데스크에서 발견" 폐기
- 규칙 원문 (String Table `ST_Notebook.S02_Rules`, GDD §6 확정 문구 그대로):
  ```
  1. 떨어진 뼈는 모두 회수해서 제자리에 두십시오.
  2. 화석의 눈구멍은 비추지 마십시오. 비어 있는지 확인하는 순간 비어 있지 않게 됩니다.
  3. 화석이 눈앞에서 사라졌다면 움직이지 마십시오.
  4. 매시 44분에는 화석을 보지 마십시오.
  ```

## 3. 뼈 운반 루프 (규칙 1)

| 항목 | 스펙 |
|---|---|
| 회수 | 뼈 액터를 조준한 채 `E` **누르고 있기** → 뼈가 카메라 앞 고정 위치로 따라온다 `[구현됨]` |
| 동시 운반 | **1개씩** `[제안]` — 왕복이 곧 게임플레이(화석 소실 반복 발동) |
| 설치 | 들고 있는 상태로 **빈 자리에 가까이 가면 자동으로 붙는다** (사정거리 기본 100cm). `E`를 떼도 사정거리 안이면 설치된다 `[구현됨]` |
| 소켓 매칭 | 자리를 미리 짝짓지 않는다. **같은 스태틱 메시**를 쓰는 자리 중 가장 가까운 빈 자리에 들어간다 `[구현됨]` |
| 운반 중 표현 | 물체가 **실제로 눈앞에 들려 보인다**. 1인칭 손 모델은 제작하지 않는다 `[확정]` — 스코프 |
| 진행 표시 | 수첩 「오늘의 업무」 체크리스트 3칸 + 설치 시 시스템 로그 |

- `[구현됨]` 짝을 미리 지정하지 않는 이유: 박물관 뼈 에셋은 메시가 `SM_MammothBone_A`~`I` 9종뿐이고 **여러 액터가 같은 메시를 공유**한다. 액터 이름의 숫자 접미사(`_B6`, `_B7`)는 메시가 아니라 이름 중복 회피 번호다. 따라서 "이 뼈는 저 자리" 식 고정 짝짓기가 성립하지 않는다. 메시가 같으면 어느 자리에 넣어도 결과가 같으므로 가장 가까운 빈 자리에 넣는다 — 배치 작업도 줄고 자석 감각도 살아난다
- `[구현됨]` 대상 지정은 **액터 태그**로 한다. 들 물체와 자리 양쪽에 `Carry` 태그를 붙이면 되고, 액터마다 컴포넌트를 붙이지 않는다. 같은 메시를 쓰는 쌍이 둘 이상이라 짝이 모호하면 양쪽에 같은 `Carry_<ID>` 태그로 직접 지정한다
- 소켓은 눈구멍 근처에 배치하지 **않는다** `[확정]` — v1.3의 "설치 동선 함정"은 폐기된 완성 역설의 잔재. 규칙 2의 위험은 소켓이 아니라 "빈 눈구멍을 확인하고 싶은 유혹" 자체가 담당 (규칙 문구가 그 유혹을 심는다)

| 유예 | 소실 후 `0.5초` `[제안]` 동안은 이동 판정을 하지 않는다 — 화석 쪽으로 **걸어오던 중** 발동하므로 손을 뗄 시간이 필요하다 `[구현됨]` |

| 해제 | 판정 시간을 버티면 화석이 **제자리에 그대로 복귀** `[구현됨]` — 아무 일도 없었던 듯이 |
| 재발동 | 쿨다운 `45초` `[제안]`. 뼈 3개 왕복이 밤2의 본체이므로 1회성이 아니라 반복 발동이어야 긴장이 유지된다 |
| 헤드램프 | 무관 `[구현됨]` — 규칙 2와 달리 빛과 무관하다. 램프를 꺼도 사라지고 판정도 돈다 |

- `[확정]` 유예 0.5초가 "경고 없음" 원칙(기둥 3)과 충돌하지 않는 근거: 유예는 위반 경고가 아니라 **입력 관성 보정**이다. 발동 순간 이미 눌려 있던 키 때문에 죽는 것은 플레이어의 판단 실패가 아니다. 유예 중에도 아무 UI를 띄우지 않는다
- `[팀 확인 필요]` AGENTS §3-3(*전시물이 움직이는 순간을 보여주는 연출 금지 — 변화는 항상 플레이어 시야 밖에서만*)과의 관계: 소실은 **움직임을 보여주지 않으므로** 기둥에 부합한다고 보지만, 시야 안에서 변화가 일어나는 것은 사실이다. 불변 조건이므로 팀 확인 권장
- **폐기**: `BP_S02_GazeZone`, `DT_GazeZones`, 존 배치(Z1~Z3), 0.5초 선행 사운드 신호

## 9. 클리어 시퀀스

```
3번째 뼈 설치 (E)
 → [0.0s] 로그 `누락 골격 회수 3/3 — 전시 상태 복원 확인`
 → [0.5s] 수첩 체크선 SFX
 → [2.0s] 앰비언스 정적 — 아무 일도 일어나지 않는 3초 [제안] (긴장의 무산 = 이 밤의 마지막 연출)
 → [5.0s] 페이드아웃 → 「Day 2」 카드 + RULE_FRAGMENT_01
 → CompleteCurrentScenario() → 밤3 로드
```

- 설치 지점 = 화석 전시대 앞이므로 페이드 직전 화석이 정면에 있다 — 카드 직전 추가 연출(그림자 등)은 넣지 않는다 `[확정]` (그림자 시스템 폐기, 기둥 2)
- 44분 창 도중 클리어한 경우: 마지막 `E` 입력이 성립했다면 즉시 `Complete` 진입, 판정 3종 전부 비활성 `[제안]` — 클리어 연출 중 사망 없음

## 12. QA 체크리스트

- [ ] 뼈 3개가 어떤 순서로든 회수·설치 가능하고 3번째 설치에서 정확히 1회 클리어 발동
- [ ] 운반 중에는 다른 뼈를 집을 수 없다 / 이미 설치된 뼈는 다시 집히지 않는다
- [ ] 자리에 가까이 가면 `E`를 떼기 전에 붙고, 멀리서 떼면 그 자리 바닥에 놓인다
- [ ] 같은 메시 뼈가 여러 개여도 각각 서로 다른 빈 자리에 들어간다 (한 자리에 겹치지 않음)
- [ ] 눈구멍: 램프 ON + 중앙 0.3초 → Failure / 0.2초에 시선 이탈 → 리셋 / **램프 OFF 응시 → 무반응**
- [ ] 눈구멍 판정이 고정 사거리(기본 1200cm) 밖에서는 발동하지 않는다
- [ ] 화석 소실: 보면서 접근 시 발동 / 등지고 접근 시 무발동
- [ ] 유예 0.5초 동안은 걸어도 안전, 그 뒤 2.0초 이동 입력 → Failure, 시점 회전만 → 안전
- [ ] 버티면 화석이 제자리에 복귀하고 쿨다운 45초 동안 재발동하지 않는다
- [ ] 44분 창: 43~45분에 화석 노출 0.3초 → Failure / 기둥 뒤 → 안전 / 램프 OFF로 보기 → Failure
- [ ] 44분 창이 4회(01/02/03/04시) 모두 동작, 예고 앰비언스는 01:42 1회만
- [ ] 화석 소실 + 44분 창 중첩: 정지 상태에서 시점 회전으로 화석을 프레임 밖에 두면 생존
- [ ] 위반 3종 각각의 Failure 후 뼈·클럭·쿨다운이 초기화되고, **배터리는 이어진다**

- [ ] 상시 램프 ON + 배터리 3개 사용 시 방전 없이 완주 가능
- [ ] 클리어 확정 후(3번째 설치 입력 성립 후) 어떤 판정도 발동하지 않는다
