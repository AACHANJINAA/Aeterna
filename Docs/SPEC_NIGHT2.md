## 1. 흐름 골격

밤2는 밤1 같은 선형 상태머신이 아니다. **업무(뼈 3개)는 자유 순서**이고, 그 위에 **상시 판정 3종**(규칙 2·3·4)이 병렬로 돈다.

```
[Boot] → [Briefing] → [Work(자유 진행)] ── 뼈 3/3 설치 → [Complete]
                          │
                          ├─ 상시: 눈구멍 응시 판정 (§6-1)
                          ├─ 상시: 화석 소실 판정 (§6-2)
                          └─ 매시 22분: 정지 판정 (§6-3)
                          └─ 위반 → [Failure] → 밤 재시작
```

| 상태 | 내용 |
|---|---|
| `Boot` | 부팅 시퀀스 (밤1과 동일 규격). 경비실 재기동 |
| `Briefing` | **「오늘의 업무」 두루마리 위젯** 자동 표시 (밤2 최초 도입 — SPEC_NIGHT1 §3-0 결정): *"오늘의 업무 — 1층 전시관 점검"* + 규칙 4개. `[확인]`으로 닫음. 닫기 전 이동 잠금 `[제안]`. 이후 `Tab` 수첩에서 상시 재열람 |
| `Work` | 클럭 시작. 뼈 3개 회수·설치 자유 진행. 판정 3종 활성 |
| `Complete` | 마지막 뼈 설치 지점에서 종료 시퀀스 (§9) |
| `Failure` | FailureSystem 위임 (§8) |

- `[확정]` 규칙 4개는 밤 시작 시 수첩에 이미 기재되어 있다 (PDF 기준). 안내 데스크 스캔 의존 없음 — v1.3의 "데스크에서 발견" 폐기
- 규칙 원문 (String Table `ST_Notebook.S02_Rules`, GDD §6 확정 문구 그대로):
  ```
  1. 떨어진 뼈는 모두 회수해서 제자리에 두십시오.
  2. 화석의 눈구멍은 비추지 마십시오. 비어 있는지 확인하는 순간 비어 있지 않게 됩니다.
  3. 화석이 눈앞에서 사라졌다면 움직이지 마십시오.
  4. 매시 22분에는 움직이지 마십시오.
  ```

## 3. 뼈 운반 루프 (규칙 1)

| 항목 | 스펙 |
|---|---|
| 회수 | 뼈 액터를 조준한 채 `E` **누르고 있기** → 뼈가 카메라 앞 고정 위치로 따라온다 `[구현됨]` |
| 동시 운반 | **1개씩** `[제안]` — 왕복이 곧 게임플레이(화석 소실 반복 발동) |
| 설치 | 들고 있는 상태로 **빈 자리에 가까이 가면 자동으로 붙는다** (사정거리 기본 100cm). `E`를 떼도 사정거리 안이면 설치된다 `[구현됨]` |
| 소켓 매칭 | 자리를 미리 짝짓지 않는다. **같은 스태틱 메시**를 쓰는 자리 중 가장 가까운 빈 자리에 들어간다 `[구현됨]` |
| 운반 중 표현 | 물체가 **실제로 눈앞에 들려 보인다**. 1인칭 손 모델은 제작하지 않는다 `[확정]` — 스코프 |
| 진행 표시 | 수첩 「오늘의 업무」 체크리스트 3칸 + 설치 시 시스템 로그 |

- `[구현됨]` 짝을 미리 지정하지 않는 이유: 박물관 뼈 에셋은 메시가 `SM_MammothBone_A`~`I` 9종뿐이고 **여러 액터가 같은 메시를 공유**한다. 액터 이름의 숫자 접미사(`_B6`, `_B7`)는 메시가 아니라 이름 중복 회피 번호다. 따라서 "이 뼈는 저 자리" 식 고정 짝짓기가 성립하지 않는다. 메시가 같으면 어느 자리에 넣어도 결과가 같으므로 가장 가까운 빈 자리에 넣는다 — 배치 작업도 줄고 자석 감각도 살아난다
- `[구현됨]` 대상 지정은 **액터 태그**로 한다. 들 물체와 자리 양쪽에 `Carry` 태그를 붙이면 되고, 액터마다 컴포넌트를 붙이지 않는다. 같은 메시를 쓰는 쌍이 둘 이상이라 짝이 모호하면 양쪽에 같은 `Carry_<ID>` 태그로 직접 지정한다
- 소켓은 눈구멍 근처에 배치하지 **않는다** `[확정]` — v1.3의 "설치 동선 함정"은 폐기된 완성 역설의 잔재. 규칙 2의 위험은 소켓이 아니라 "빈 눈구멍을 확인하고 싶은 유혹" 자체가 담당 (규칙 문구가 그 유혹을 심는다)

### 6-2. 규칙 3 — 화석 소실 (근접 발동)

> **2026-08-25 규칙 개정** — 원문 *"화석이 당신을 바라보고 있다면 움직이지 마십시오"* 를

### 6-3. 규칙 4 — 매시 22분 정지

> **2026-08-25 규칙 개정** — 원문 *"매시 44분에는 화석을 보지 마십시오"* 를
> *"매시 22분에는 움직이지 마십시오"* 로 바꾼다. 시야 판정을 쓰지 않으므로
> 화석 샘플 4점·프러스텀·가림 판정이 통째로 불필요해진다.

| 항목 | 스펙 |

| 발생 횟수 | 01:22 / 02:22 / 03:22 / 04:22 — **총 4회, 전부 동일 판정** `[확정]` |
| 위반 조건 | 창 내에 **이동 입력(WASD·Shift)** 발생 시 즉시 Failure. **시점 회전은 허용** `[구현됨]` |

- **폐기**: 시야 프러스텀 판정, 화석 샘플 4점, 가림 판정, `E_44_Warn` 예고 앰비언스

## 9. 클리어 시퀀스

```
3번째 뼈 설치 (E)

```

- [ ] 화석 소실: 보면서 접근 시 발동 / 등지고 접근 시 무발동
- [ ] 유예 0.5초 동안은 걸어도 안전, 그 뒤 2.0초 이동 입력 → Failure, 시점 회전만 → 안전

- [ ] 22분 창: 창 중 이동 입력 → Failure / 시점 회전만 → 안전 / 램프 상태와 무관

### 규칙 2 — 눈구멍 응시: 판정이 완화됐다

| 항목 | 스펙 | 구현 | 사유 |
|---|---|---|---|
| 시야 중앙 콘 반각 | 6° | **12°** | 6°는 화면 정중앙에 정확히 두어야만 걸려, 눈을 보고 있는데도 발동하지 않았다 |
| 가림 판정 | 사용 (기둥·진열장 뒤 = 안전) | **기본 해제** (`bRequireLineOfSight = false`) | 눈알이 두개골·벽 안쪽에 박혀 있으면 자기를 가린 것으로 잡혀 영원히 걸리지 않았다 |
| 응시 시간 | 0.3초 | 0.3초 (그대로) | |
| 사거리 | 1200cm | 1200cm (그대로) | |

- **가림 판정 해제의 대가**: 벽 너머에서 눈 방향을 보는 것만으로도 위반이 된다.
  "안 보이는데 죽었다"는 반응이 나오면 `Require Line Of Sight`를 다시 켜고
  눈알을 벽 표면 20cm 안으로 당기는 쪽이 원래 설계 의도에 가깝다.
  라인트레이스 코드는 지우지 않고 플래그 뒤에 남겨뒀다
- 눈알 에셋 배치 완료 (`BP_S02_Eye`, `Eye` 태그, 4개). 판정 기준점은 **액터 원점 한 점**이므로
  메시 피벗이 눈 중심에 있어야 한다. 배치 스케일이 곧 다 나타났을 때의 크기다

### 규칙 3 — 화석 소실: 밤당 1회로 바뀌었다

| 항목 | 스펙 | 구현 |
|---|---|---|
| 재발동 | 쿨다운 45초 후 반복 | **밤당 1회** (`bTriggerOnce = true`) |

스펙은 "반복 발동이어야 긴장이 유지된다"고 봤으나, 실제로는 주기적으로 사라져
사건이 아니라 배경이 됐다. `BeginFreeze`에서 플래그가 서고 밤 시작·재시작에만 풀린다.
되돌리려면 `Trigger Once`를 끄면 쿨다운 방식으로 돌아간다.

### 클럭 배속

스펙 §5는 `0.2`(밤 전체 실시간 20분)이나 **구현은 `1.0`** 이다 (실시간 1초 = 게임 1분).
22분 정지 창이 실시간 1초로 줄어드는 셈이므로, 규칙 4를 구현할 때 재검토가 필요하다.
