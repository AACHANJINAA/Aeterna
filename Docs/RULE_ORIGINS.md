# Rule Origins

## 목적

이 문서는 규칙별 출처, 원인 실패, 설계 의도, 통합 이력을 보관하는 장부입니다.

- 평소 작업에서는 읽지 않습니다. 규칙을 추가·수정·삭제하거나 재검증할 때만 참조합니다.
- 실제 행동 규칙은 각 담당 문서에 두고, 이 문서에는 출처와 변경 이유만 기록합니다.
- 기록 절차는 `Docs/HARNESS.md`의 `규칙 추가 판단`을 따릅니다.

## 출처 유형

- `기획`: 제공된 Aeterna 시나리오 프로토콜에서 직접 나온 기준
- `이식`: 제공된 기존 하네스 문서에서 Aeterna에 맞게 이식한 기준
- `실패`: 실제 실패에서 나온 규칙
- `예방`: 실패 없이 예측으로 추가한 기준
- `설계`: 의도적 작업 환경 설계 결정
- `통합`: 여러 문서의 중복 규칙을 한 담당 문서로 모은 결정
- `기억 안 남`: 출처 미상이며 재검증 최우선 대상

## 2026-08-14 — GDD v1.3 기준 전체 정합화

초기 하네스는 GDD v1.2 이전의 `8개 30분 시나리오 / 경비실 복귀` 모델로 작성되어 있었고, 이후 확정된 GDD v1.3과 정면 충돌하고 있었다. AGENTS.md가 "충돌 시 GDD 우선"을 선언하고 있으므로 GDD를 단일 원본으로 삼아 전 문서를 정합화함.

| 폐기된 기준 | 대체 기준 | 영향 문서 |
|---|---|---|
| S01~S08 (8개 시나리오) | S01~S03 (밤 3개, 확장은 GDD §11에서 착수 금지) | ARCHITECTURE, STYLEGUIDE, TASK_WRITING, PLANS, AUDIT_LOG, MAKE_REQUEST |
| 01:00~05:00의 30분 슬롯 분할 | 밤 1개 = 01:00~05:00 전체, GameClock은 시각 이벤트 브로드캐스트 | ARCHITECTURE, TESTING, PLANS, AUDIT_LOG, MAKE_REQUEST |
| 클리어 후 경비실 복귀 | 완료 지점 페이드아웃 →「Day N」카드 → 다음 밤 재기동 (밤 시작만 경비실) | ARCHITECTURE, TESTING, TASK_WRITING, PLANS, AUDIT_LOG |

부수 조치:

- `AGENTS.md` §3 제목을 `Aeterna 기획 기준`으로 변경 — 하네스 문서 6곳이 참조하던 이름이 실제로 없었음 (`기억 안 남` 상태 해소).
- `AGENTS.md` §9 문서 지도 신설 — 진입점이 `Docs/` 하위 문서 목록을 갖고 있지 않아 에이전트가 하네스 문서의 존재를 알 수 없었음.
- `CLAUDE.md`에서 AGENTS.md 중복 금지 목록 제거 — 한쪽만 수정되어 충돌하는 드리프트 경로를 차단.
- `CLAUDE.md`에 저장소 판별 절차 추가 — Git 저장소가 아닌 문서 폴더에서 `git lfs locks`를 실행하도록 지시하고 있었음.
- GDD §10에 결정 대기 #9~#15 추가 — 문서 간 충돌이 아니라 GDD 자체의 미결 항목(수첩 페이지 넘김 입력, 배터리 방전 소프트락, 밤2 04:44 트리거, 밤3 실패 판정 이중 정의, 규칙 2의 램프 OFF 판정, RULE_FRAGMENT 넘버링, 밤1 위반 처리)이므로 임의로 결정하지 않고 결정 대기로 등록.
