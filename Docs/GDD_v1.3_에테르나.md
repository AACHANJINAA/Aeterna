# 1. 게임 개요

## 1-1. 하이 콘셉트

> **"낡은 박물관의 야간 관리 로봇 M-05가 되어, 전임자가 남긴 수첩의 규칙을 지키며 밤의 점검 업무를 완수하라. 수첩과 다른 행동을 하는 순간 — 게임 오버, 그 밤은 처음부터 다시 시작된다."**

## 1-2. 코어 루프 (확정)

```
[경비실] 재기동 (밤 시작)
   ↓
수첩 확인 (오늘 밤의 업무 + 규칙)
   ↓
해당 장소로 이동
   ↓
퀘스트 진행  ──  수첩과 상이한 행동 → [게임 오버] → 밤 처음부터 재기동
   ↓
퀘스트 완료 → 페이드아웃 → 「Day N」 카드 표시
   ↓
다음 밤, [경비실] 재기동
```

- 밤1(튜토리얼) → **Day 1** → 밤2 → **Day 2** → 밤3 → **Day 3** → 엔딩
- **경비실 복귀 없음**: 마지막 목표를 완료한 그 자리에서 화면이 페이드아웃되고, 검은 화면에 「Day N」 타이틀 카드(+ RULE_FRAGMENT 획득 표시)가 뜬 뒤 다음 밤의 경비실 재기동으로 이어진다. 밤의 시작만 경비실 고정
- 밤은 확장 가능한 단위: 추후 시나리오가 추가되면 밤3과 엔딩 사이(또는 엔딩 이후 추가 근무)로 삽입한다 (§11)
- **게임 오버 = 실패 연출 후 현재 밤을 처음부터 재시작** (이전 밤 클리어 기록·해금 요소는 유지)

## 1-3. 디자인 기둥

1. **업무는 평범하게, 규칙은 기이하게** — 공포는 수첩 규칙과 실제 상황의 충돌에서만 발생
2. **보여주지 않는 공포** — 전시물이 움직이는 순간은 절대 보여주지 않는다 (시야 밖 변경만)
3. **판단은 플레이어 몫** — 위반 직전 경고 없음. 규칙을 기억하고 해석하는 것이 게임플레이
4. **기능 최소주의** — 조작 5종 이외의 기능은 만들지 않는다 (4인 팀 스코프 방어)

# 3. 플레이어 — M-05

## 3-1. 기본 사양

| 항목 | 내용 |
|---|---|
| 시점 | 1인칭 (로봇 카메라 = 화면, 미세 스캔라인 포스트프로세스) |
| 기동 연출 | 밤 시작·게임 오버 후 재기동 시 부팅 시퀀스 (암전 → 시스템 로그 스크롤 → 카메라 온) |
| 사망 개념 없음 | 게임 오버 = 기능 정지 → 백업 재기동 (세계관적 롤백 설명) |

## 3-2. 헤드램프 & 플레이어 배터리 시스템

조명은 별도 아이템이 아니라 **M-05 머리 위에 내장된 헤드램프**다 (`F` ON/OFF).
배터리는 **플레이어(M-05) 배터리** 하나로 통합된다 — **M-05 본체 전원과 헤드램프 전원을 겸하는 단일 배터리**이며, 헤드램프가 이 배터리를 소모한다.

| 항목 | 사양 |
|---|---|
| 헤드램프 | M-05 내장 — 획득 과정 없음, 밤1 시작부터 사용 가능. 빛 방향 = 시선 방향 |
| 소모 | 헤드램프 ON 동안 플레이어 배터리 감소 (OFF 시 소모 없음) |
| **밝기 연동** | **잔량이 줄어들수록 헤드램프가 연속적으로 어두워진다** — 아래 「잔량-밝기 연동」 참조 |
| 방전 시 | 헤드램프 사용 불가 — 어둠 속 이동 강제 (게임 오버 아님, 단 규칙 수행이 어려워짐) ※ "방전 = M-05 기능 정지" 여부는 결정 대기 (§10 #8) |
| 충전 | 맵 곳곳에 주기적으로 배치된 배터리에 `E` → 즉시 충전 |
| 배치 | 경비실 + 각 구역 파밍 포인트 (벤치 아래, 분실물 상자, 단말 옆 등 / 밤마다 리셋) |

### 잔량-밝기 연동 (확정)

배터리는 본체와 헤드램프를 함께 먹이므로, **전압이 떨어지면 빛도 약해진다**는 물리적 인과를 그대로 게임에 쓴다.
잔량이 줄어들면 아래 3개를 **함께** 감쇠시킨다.

| 파라미터 | 잔량 만충 → 방전 직전 | 역할 |
|---|---|---|
| 강도 (Intensity) | 밝음 → 어두움 | 전체 광량 |
| **도달 거리 (Attenuation Radius)** | 멀리 → 발밑만 | **체감의 핵심** — 빛이 닿는 거리가 줄어야 "좁아진다"가 느껴진다 |
| 색온도 | 백색 → 노랑·주황 | 전압 강하의 다이어제틱 표현 |

- **연속값으로 감쇠한다.** UI 게이지는 칸 단위로 표시하지만 밝기는 칸 경계에서 뚝 떨어지지 않는다 — 칸이 깎일 때만 어두워지면 플레이어가 "칸이 남아 있으면 안전"으로 학습해 긴장이 끊긴다.
- 감쇠는 **선형이 아니라 후반 가중**을 권장: 초반에는 거의 눈치채지 못하다가 후반에 급격히 조여드는 곡선. (정확한 곡선은 §10 #3 튜닝)
- 마지막 1칸의 **점멸**은 이 연속 감쇠 위에 얹히는 별개 신호다 (아래 UI 항목).
- 방전(0) 시에는 감쇠의 연장이 아니라 **소등**된다 — 헤드램프 사용 불가.

**설계 의도**

- **밝기 자체가 다이어제틱 배터리 게이지가 된다.** 플레이어는 구석의 UI 위젯을 보지 않아도 "요즘 잘 안 보이네"로 잔량을 체감한다 — §7의 "정보의 출처" 원칙과 어긋나지 않으면서 HUD 의존을 줄인다.
- 자원 관리의 압박이 숫자가 아니라 **시야 폭**으로 전달된다. "언제 켜고 언제 끌 것인가"의 대가가 즉각 보인다.
- 어두워질수록 다음 배터리를 찾기 어려워지는 **하강 나선**이 생긴다. 긴장 장치인 동시에 소프트락 위험이므로 완화 장치가 필요하다 (§10 #10).

**플레이어 배터리 UI (상시 표시)**

```
🔋 ▮▮▮▯▯      ← 배터리 잔량 칸 게이지 (예: 5칸)
```

- 잔량은 숫자가 아닌 **칸(ㅁㅁㅁ) 단위 게이지**로 표시 — 화면 구석 소형 위젯 (UI 에셋 활용, §7)
- 마지막 1칸 진입 시 게이지 점멸 + 헤드램프 **점멸**(깜빡임) 추가 — 연속 감쇠로 이미 어둡고 누래진 상태 위에 얹히는 **별개의 경고 신호**다. 색 변화는 감쇠 곡선이 담당하고, 점멸은 마지막 1칸에서만 발생한다
- "언제 켜고 언제 끌 것인가"가 자원 관리의 핵심
- 헤드램프 빛이 시선과 일치하므로, **"비추지 마라" 계열 규칙(밤2 눈구멍)은 곧 "보지 마라"와 동일 판정**이 됨 — 응시 판정 하나로 통합 가능 (구현 단순화)

## NIGHT 1 — 「인수인계」 (튜토리얼)

| 항목 | 내용 |
|---|---|
| 게임 내 시간 | 01:00 ~ 05:00 (업무 밀도가 낮아 클럭 가속, 실플레이 15~20분) |
| 주요 구역 | 경비실 → 순찰 지점 A/B/C (위치 TBD, 레벨 디자인 확정 후) → 마지막 지점에서 종료 |
| 실패 조건 | 없음 (안전한 밤 — 조작·동선 학습 전용) |
| 해금 | 수첩, 스캔 기능, 배터리 충전 (헤드램프는 내장 — 획득 없음) |

### 흐름

**① 재기동 (01:00, 경비실)**
- 암전 화면에 시스템 로그가 스크롤되며 부팅: `M-05 RESTORE... CAMERA ON`
- 책상 위 오브젝트를 순서대로 상호작용 (순서 강제 튜토리얼):
  1. `E` 쪽지 읽기 — *"수첩에 적힌 것만 지키면 아무 일도 없습니다. — 前 야간 관리 담당"* (인간인지 이전 기체인지 모호)
  2. 부팅 로그 말미에 `HEADLAMP: READY` → `F` 헤드램프 ON/OFF 안내 (내장 장비, 획득 불필요)
  3. `E` 수첩 획득 → `Tab` 펼침 안내

**② 수첩 확인**
- 수첩 p.1 「기본 수칙」:
  ```
  하나. 근무 시간은 01:00 ~ 05:00. 05:00 전에는 밖으로 나가지 마시오.
  둘.   배터리를 아껴 쓰시오. 어둠 속에서는 규칙도 읽을 수 없습니다.
  셋.   순찰은 "일"입니다. 일을 하지 않으면, 저쪽도 일을 시작합니다.
  ```
- 수첩 p.2 「오늘의 업무」: 순찰 체크포인트 3곳 스캔 (지점 A / B / C — 순서 무관)

**③ 순찰 (조작·공간 학습)**

> ⚠️ **순찰 지점의 구체적 위치는 미정.** 박물관 레벨 디자인 확정 후 배치한다.
> 아래는 지점에 얹을 "연출 비트" 목록이며, 어느 지점에 어떤 비트를 붙일지는 레벨 확정 시 결정.

- 경비실 문 밖은 완전한 어둠 → 헤드램프 강제 학습 (공통, 위치 무관)
- 순찰 지점 3곳(A/B/C, 위치 TBD)을 `E` 스캔 — 동선이 박물관 주요 구역을 한 바퀴 돌도록 배치하는 것만 확정
- 지점에 배분할 연출 비트:
  - **비트 1 — 화석 무대 인사**: 공룡 화석이 보이는 지점에서 헤드램프 빛(=시선)이 골격을 훑도록 유도. 화석은 미동도 없음 (밤2 예고)
  - **비트 2 — 배터리 충전 학습**: 동선 중간에 배터리 배치, `E` 충전 학습 (시작 잔량을 낮게 세팅해 자연스럽게 유도)
  - **비트 3 — 실체 없는 소리**: 스캔 직후 어둠 속에서 `달그락` 1회 — 비추면 아무것도 없음 (공포 후불제)
  - **비트 4 — 빈 진열장 복선**: 비어 있는 진열장 스캔 시 로그 `전시물 미등록. 명패: "수각류 앞발 골격"` (밤2 복선)

**④ 종료 (마지막 순찰 지점)**
- 3곳 완료 시 수첩에 체크선 자동 기입 → 그 자리에서 페이드아웃 → **「Day 1」 카드** + `RULE_FRAGMENT_03` 획득 표시
- `RULE_FRAGMENT_03` *"읽는 자가 있어야 규칙도 있다."* (텍스트 확정 필요)

## NIGHT 2 — 「중앙홀의 공룡 화석」

| 항목 | 내용 |
|---|---|
| 게임 내 시간 | 01:00 ~ 05:00 (뼈 이벤트: 01:44 / 02:44 / 03:44, 최종 점검 04:44) |
| 주요 구역 | 경비실 → 중앙홀(메인) ↔ 전시 회랑 · 2층 난간 |
| 겉 업무 | 시스템 로그 `NIGHT EXHIBIT CHECK: ACTIVE` — 공룡 화석 누락 골격 3개 확인 |
| 핵심 반전 | 뼈 3개를 모두 회수하되, **화석을 "완성"하면 안 된다** |

### 규칙 (확정 — 4개. 경비실 수첩 유도 → 중앙홀 안내 데스크에서 발견, 스캔 시 수첩에 필사)

```
1. 떨어진 뼈는 모두 회수하라. 단, 화석을 완성하지 마라.
2. 화석의 눈구멍을 비추지 마라. 비어 있는지 확인하는 순간 비어 있지 않게 된다.
3. 화석에게 그림자가 없으면 움직이지 마라.
4. 44분에는 화석을 보지 마라.
```

**규칙별 게임플레이 역할**

| 규칙 | 유형 | 판정 |
|---|---|---|
| 1 | 목표 + 역설 (모두 회수하되 완성 금지) | 마지막 뼈를 화석에 장착하는 순간 게임 오버 |
| 2 | 응시 금지 | 헤드램프 빛 = 시선이므로 눈구멍을 일정 시간 시야 중앙에 두면 게임 오버 (응시 판정 단일화) |
| 3 | 정지 강제 | 그림자 소실 상태에서 이동 입력 시 게임 오버 |
| 4 | 시간대 시선 금지 | 매시 44분(±판정 유예)에 화석이 시야에 들어오면 게임 오버 — **뼈가 사라지는 순간을 절대 볼 수 없게 만드는 장치** |

### 흐름

**① 재기동·수첩 확인 (01:00)** — 수첩 신규 페이지: *"중앙홀 안내 데스크의 수칙을 먼저 읽을 것."* → 중앙홀 이동, 데스크 스캔으로 규칙 4개 획득

**② 1단계 — 꼬리뼈 (01:44)**
- 01:44 직전, 시계 UI와 앰비언스 변화로 "44분이 온다"를 예고 → 플레이어는 화석에서 **등을 돌리거나 시야에서 치워야 함** (규칙 4)
- 44분이 지나면 화석 꼬리뼈가 사라져 있음. 바닥에 끌린 자국이 위치 힌트
- 꼬리뼈 회수(`E`) → 화석에 장착(`E`)
- 장착 순간, 그림자만 플레이어 쪽으로 고개를 돌림 (실물은 부동)

**③ 2단계 — 갈비뼈 (02:44)**
- 02:44 규칙 4 재발동 (이번엔 예고 연출 약화 — 플레이어가 스스로 시계를 봐야 함)
- 갈비뼈는 전시 회랑 진열장에 "초승달 모양 유물"로 잘못 전시됨 → 회수 시 중앙홀 발소리 SFX 1회 추가
- 회수·장착 과정에서 눈구멍 근처를 비추게 되는 동선 함정 배치 (규칙 2의 실전 시험)
- 이 구간부터 **그림자 소실 이벤트** 랜덤 발동: 화석 그림자가 사라지면 즉시 정지 (규칙 3) — 수 초 후 그림자가 돌아오면 이동 재개

**④ 3단계 — 마지막 뼈 · 아래턱 (03:44)**
- 03:44 규칙 4 발동 후 아래턱 소실
- 아래턱뼈는 전시대 뒤쪽에서 발견 — **회수는 하되 장착하면 화석이 "완성"됨** (규칙 1의 역설)
- 정답: 장착하지 않고 중앙홀 보관함에 `E`로 보관 → 시스템 로그 `누락 골격 3/3 회수 완료. 전시 상태: 미완성 — 확인.`

**⑤ 점검 종료 (04:44 전)**
- 점검 종료 단말 작동 → 종료 직후 등 뒤에서 턱뼈 맞물리는 소리 — 규칙 4의 시간(04:44)이므로 **돌아보면 화석이 시야에 들어와 게임 오버** → 돌아보지 않은 채 수 초 버티면 페이드아웃 → **「Day 2」 카드**

### 클리어 / 실패

- 클리어: 뼈 3개 모두 회수, 2개만 장착(아래턱은 보관함), 눈구멍 미조준, 그림자 소실 시 정지 준수, 매 44분 화석 미목격, 04:44 전 종료
- 게임 오버 (= 규칙 위반): ① 아래턱 장착으로 화석 완성 ② 눈구멍 조준 ③ 그림자 없는 상태에서 이동 ④ 44분에 화석 목격 (점검 종료 후 뒤돌아봄 포함)
- 실패 연출: 전 조명 소등 → 턱이 닫히는 소리 → 바닥에 떨어진 카메라 시점 → 로그 `추가 골격 1개: 야간 관리 유닛 M-05`
- 클리어 연출: 페이드아웃 직전, 그림자만 아래턱을 찾듯 홀을 훑음 → 「Day 2」 카드에 `RULE_FRAGMENT_01` 획득 표시

## NIGHT 3 — 「켜져 있으면 안 되는 불」

| 항목 | 내용 |
|---|---|
| 게임 내 시간 | 01:00 ~ 05:00 (핵심 시각: 03:03 확인등) |
| 주요 구역 | 경비실 → 중앙홀 ↔ 2층 복도 · 진열장 구역 → 배전실 |
| 겉 업무 | 시스템 로그 `NIGHT LIGHT CHECK: ACTIVE` — 01시 이후 켜진 비정상 조명 소등 |
| 핵심 반전 | "켜진 불은 끄시오" vs "03:03의 불은 건드리지 마시오" — **규칙 1과 3의 충돌을 스스로 판별**해야 한다 |
| 밤-간 연속성 | 도입부: 어젯밤 보관함에 넣은 아래턱뼈가 화석에 다시 붙어 있음 → 스캔 시 로그 `등록되지 않은 변경 사항` |

### 규칙 (확정 — 3개. 배전반 옆 발견, 스캔 시 수첩에 필사)

```
1. 1시 이후 켜진 불은 끄시오. 박물관에 다른 근무자는 없습니다.
2. 붉은 비상등 아래에서 멈추지 마시오.
3. 03:03에 켜지는 불은 근무자를 확인하는 불입니다. 건드리지 마시오.
```

**규칙별 게임플레이 역할**

| 규칙 | 유형 | 판정 |
|---|---|---|
| 1 | 업무 목표 + 불길한 암시 ("다른 근무자는 없다"인데 불은 계속 켜진다 — 그럼 누가?) | 켜진 불을 방치한 채 점검 종료 시 실패 |
| 2 | 이동 제약 | 붉은 비상등 라이트 볼륨 안에서 일정 시간(예: 3초) 이상 정지 시 게임 오버 |
| 3 | 규칙 1과의 충돌 — **예외를 식별하는 판단력 시험** | 03:03에 켜진 그 불을 조작(소등)하면 게임 오버 |

> 이 밤의 공포 문법: 규칙 1을 성실히 수행할수록 "그럼 이 불들은 누가 켜는가"라는 질문이 쌓이고,
> 03:03에 켜진 불 하나만은 **끄면 안 되는 예외**임을 플레이어가 스스로 구분해야 한다.

### 흐름

**① 재기동·규칙 획득 (01:00)**
- 도입: 중앙홀 화석 스캔 시 아래턱뼈가 다시 붙어 있음 — 로그 `등록되지 않은 변경 사항` (밤2 연속성)
- 배전반 옆 수칙 스캔 → 규칙 3개 필사

**② 소등 순찰 1차 (01:00~02:30)**
- 박물관 곳곳의 조명(벽등·보조등 등 4~5개)이 시간차를 두고 하나씩 켜짐 — 시스템 로그가 점등을 통지: `비정상 점등 감지: 2층 복도`
- 플레이어는 켜진 불을 찾아가 `E`로 소등 (규칙 1 수행)
- 이동 중 붉은 비상등 구간이 동선을 가로지름 — 그 아래에서는 멈추지 말 것 (규칙 2). 소등할 조명이 하필 붉은 비상등 옆에 있는 배치로 긴장 유발
- 끈 불이 등 뒤에서 다시 켜지는 연출 1회 (뒤돌아보면 이미 켜져 있음 — "다른 근무자는 없습니다"의 회수)

**③ 03:03 — 확인등 (판단력 시험)**
- 03:03 정각, 조명 하나가 켜지고 시스템 로그: `비정상 점등 감지` — **여느 점등 통지와 똑같은 형식**
- 규칙 1대로라면 꺼야 하지만, 규칙 3의 예외임을 기억해야 함. 시각(03:03)이 유일한 식별 근거 → 시계 UI 확인이 생존 행동이 되는 순간
- 이 불은 조작 금지. 접근해 스캔만 하면 로그: `광원 분석 불가` (으스스한 피드백만 주고 방치가 정답)
- 끄면 안내 방송 `근무자 미확인` → 게임 오버 연출 진입

**④ 소등 순찰 2차 + 점검 종료 (03:03~05:00)**
- 남은 비정상 조명 소등 완료 → 배전반에서 점검 종료
- 종료 조건: 03:03 확인등을 **제외한** 모든 비정상 조명 소등 상태
- 종료 단말 작동 지점에서 페이드아웃 → 엔딩 시퀀스 (경비실 복귀 없음)

### 클리어 / 실패

- 클리어: 03:03 확인등을 제외한 비정상 조명 전부 소등, 붉은 비상등 아래 정지 없음, 05:00 전 배전반 점검 종료
- 게임 오버 (= 규칙 위반): ① 붉은 비상등 아래 일정 시간 정지 ② 03:03 확인등 조작 / 실패(재시작): 비정상 조명 방치 상태로 05:00 도달
- 실패 연출: 전소등 → 야간 모드에도 아무것도 안 보임 → 조명이 하나씩 재점등, 각 불빛 아래 M-05형 그림자가 서 있음
- 클리어 연출: 페이드아웃 직전, 어두워진 박물관에 03:03의 불 하나만 남아 있음 — 그 불이 천천히 꺼진다. *근무자 확인 완료.*
- **최종 밤**: 「Day 3」 카드 + `RULE_FRAGMENT_02` 획득 표시 → RULE_FRAGMENT 3개 회수 엔딩 시퀀스 (아침 햇살이 드는 중앙홀 등, 연출 별도 기획)

# 7. UI / UX — 에셋 활용 방침

UI는 마켓플레이스 UI 에셋(위젯 팩)을 사용하고, 게임 고유 요소만 커스텀한다.

| UI 요소 | 방식 | 조달 |
|---|---|---|
| 화면 시계 | 상시 소형 시계 위젯 (별도 조작 없음 — T키 시계 확인 기능은 **폐기**) | 에셋 |
| 플레이어 배터리 UI | 잔량 칸 게이지 (`🔋 ▮▮▮▯▯` 형식), 마지막 칸 점멸. **잔량은 헤드램프 밝기로도 상시 전달되므로**(§3-2) 이 위젯은 보조 지표다 — 작고 눈에 덜 띄게 | 에셋 |
| 상호작용 프롬프트 | 조준 시 `[E]` 컨텍스트 표시 (스캔/회수/교체 등 라벨 가변) | 에셋 |
| 수첩 | Tab 풀스크린/반화면 수첩 뷰. 페이지 넘김 | 에셋 (저널/노트 UI 팩) + 손글씨 폰트(눈누 상업용 무료) |
| 시스템 로그 | 화면 상단 타자기식 텍스트 (부팅/스캔/연출용) | 에셋 타이핑 위젯 or 간단 자체 제작 |
| 부팅/게임 오버 시퀀스 | 풀스크린 로그 스크롤 | 자체 제작 (단순) |
| 「Day N」 카드 | 밤 완료 시 페이드아웃 후 풀스크린 타이틀 (Day 1/2/3) + RULE_FRAGMENT 획득 표시 | 자체 제작 (단순) |
| 자막 | 로그·연출음 표기 (접근성) | 에셋 |

- 다이어제틱 원칙은 "정보의 출처"에 유지(규칙은 수첩에서만), 표시 자체는 에셋 위젯으로 실용화
- 로봇 시점이므로 화면 UI가 "M-05의 HUD"라는 세계관적 정당성이 있음 — 시계·게이지 상시 표시가 설정과 충돌하지 않음

# 11. 시나리오 확장 계획 (출시 이후 / 여유 발생 시)

밤 3개는 출시 기준 최소 구성이며, 시나리오는 추후 계속 추가할 수 있는 구조로 설계한다.

## 11-1. 확장 원칙

- 새 시나리오도 동일한 프레임을 따른다: **경비실 시작 / 하룻밤(01:00~05:00) / 수첩 규칙 / 위반 = 게임 오버 / 완료 지점 페이드아웃 → 「Day N」 카드 + RULE_FRAGMENT**
- 조작 5입력 체계는 확장 시나리오에서도 불변 (기능 최소주의 유지)
- 신규 전시물 에셋 1~2종 + 규칙 세트만 있으면 시나리오 1개가 성립하도록 — 전시관 하나 = 괴담 하나

## 11-2. 후보 아이디어 (미확정 — 브레인스토밍 단계)

| 후보 | 소재 | 규칙 훅 (예시) |
|---|---|---|
| 중세 기사 갑옷 | 무기·갑주 전시관 | "갑옷의 개수를 세지 마시오." / "투구의 면갑이 열려 있으면 닫아 주시오. 안을 보지 말고." |
| (추가 후보 슬롯) | 이집트관, 해양관, 초상화 전시실 등 | 팀 브레인스토밍으로 채움 |

- 후보는 아이디어 풀일 뿐 스코프에 포함하지 않는다. **밤 3개 완성 전에는 착수 금지** (스코프 방어)

## 11-3. 시스템 확장 대비 (지금 해두면 되는 것)

- ScenarioManager의 시나리오 목록을 하드코딩하지 않고 DataTable 기반으로 (완료 시 자동으로 다음 행 로드)
- RULE_FRAGMENT 넘버링과 엔딩 조건을 "전체 개수 대비"로 판정 (3개 고정 아님)
- 서브레벨 네이밍 규칙에 확장 관 이름 여지 (`Sub_ArmoryHall` 등)
- 밤-간 변화 스폰 테이블을 시나리오 ID 키로 일반화
