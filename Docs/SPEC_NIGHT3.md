## 1. 흐름 골격

```
[Boot] → [Briefing] → [Work(소등 순찰)] ── 5/5 소등 → [TerminalReady] → 배전반 E → [Complete]
                          │
                          ├─ 스케줄: 조명 시간차 점등 (§3)
                          ├─ 03:03: 확인등 점등 (§4)
                          ├─ 랜덤 1회: 빨간 불 → [Flee] → 경비실 도달 → Work 복귀 (§5)
                          └─ 위반 → [Failure] → 밤 재시작
```

| 상태 | 내용 |
|---|---|
| `Boot` | 부팅 시퀀스 (공통 규격). 경비실 재기동 |
| `Briefing` | 「오늘의 업무」 두루마리 위젯: *"오늘의 업무 — 2층 전시관 점검"* + 규칙 3개. 이동 잠금 → `[확인]` |
| `Work` | 클럭 시작. 점등 스케줄 가동. 소등 업무 자유 진행 |
| `Flee` | 빨간 불 발동 ~ 경비실 도달 (§5). 도달 시 `Work` 복귀 — **조명·업무 상태는 전부 보존** `[확정]` |
| `TerminalReady` | 확인등 제외 5개 소등 완료 + 빨간 불 이벤트 소화 완료 (§6 게이트) |
| `Complete` | 배전반 종료 → 클리어 시퀀스 (§7) |

- 규칙 원문 (밤 시작 시 수첩 기재 `[확정 — 밤2와 동일 방식]`, `ST_Notebook.S03_Rules`):
  ```
  1. 1시 이후 켜진 불은 끄십시오. 박물관에 다른 근무자는 없습니다.
  2. 03:03에 켜지는 불은 근무자를 확인하는 불입니다. 건드리지 마십시오.
  3. 빨간색 불이 켜지는 걸 목격하셨다면 경비실로 도망치십시오.
  ```

## 4. 03:03 확인등 (규칙 2)

| 항목 | 스펙 |
|---|---|
| 점등 | 03:03 정각. 로그는 여느 점등과 **똑같은 형식** `[확정]` |
| 조작 판정 | 확인등에 `E`(소등 시도) → **즉시 Failure** (`S03_TouchedCheckLight`). 프롬프트는 다른 조명과 동일하게 `[E] 소등`으로 표시된다 `[확정]` — 프롬프트가 경고해 주면 시험이 성립하지 않는다 |
| 수동 피드백 | 확인등을 조준(시야 중앙 콘, `E` 미입력)하면 3초 후 로그 1회: `광원 분석 불가` `[제안]` — 으스스한 피드백, 방치가 정답이라는 유일한 힌트 |
| 지속 | 05:00까지 점등 유지. 소등 카운트에 미포함 (필요 소등 = L1~L5의 5개) |
| Failure 연출 진입부 | 안내 방송 `근무자 미확인` → 공통 실패 연출 (§8) `[확정 — GDD]` |

- `[제안]` 03:03 직전 플레이어가 확인등 바로 옆에 있다가 점등 순간 반사적으로 `E`를 누르는 오탐 방지: 점등 후 **1.0초간 상호작용 무시** (실패도 소등도 아님 — 입력 무반응). 이후부터 판정 유효

## 5. 빨간 불 이벤트 (규칙 3) — 팀 결정 반영

| 항목 | 스펙 |
|---|---|
| 발동 시각 | 밤 시작 시 `RedLightTime = Random(120, 270)` 게임분 추첨 `[확정: 팀 결정 ①]`. 단 **02:55~03:15 (175~195) 제외** `[제안]` — 확인등 이벤트와 겹침 방지 (재추첨) |
| 발동 | 해당 시각에 적색등 후보 3곳 중 1곳 추첨 점등 `[제안]` + 시스템 로그: `비정상 점등 감지: 적색` `[확정: 팀 결정 ②]` — 로그 형식은 동일 계열이되 색 정보가 붙는다. 플레이어 시야·위치 무관하게 발동 (M-05 센서 감지 = 목격) |
| 목표 | 경비실 실내 트리거 볼륨 진입 |
| 제한 시간 | **실시간 40초** `[제안]`, **비표시** `[확정: 팀 결정 ③]`. 산정 근거: 2층 최원거리 → 경비실 달리기 실측 + 25% 여유로 M1에서 캘리브레이션 — "달리면 반드시 살고, 걸으면 죽을 수 있는" 값 |
| 긴박감 연출 (UI 없이) | 발동 순간: 전 조명 붉은 기 가산 + 저음 드론 시작 → T-15초: 드론 증폭 + 심박형 펄스 SFX → T-5초: 화면 가장자리 비네트 미세 맥동 `[제안]`. 숫자·게이지 일절 없음 |
| 도달 성공 | 경비실 진입 → 문 닫힘 SFX (연출용 — 실제 잠금 없음) → 3.0초 대기 → 적색등 소등 + 드론 정지 → 로그: `적색 광원 소멸 — 업무를 재개하십시오` `[제안]` → `Work` 복귀. **조명·소등 진행 상태 전부 보존** |
| 도달 실패 | 제한 시간 초과 → **즉시 Failure** (`S03_FleeTimeout`), 현재 위치에서 연출 (§8) |
| Flee 중 다른 판정 | 확인등 조작 판정은 유지 `[확정]` (도망 중에도 `E`를 누르면 위반 — 다만 시각 제외 규칙으로 Flee와 03:03은 겹치지 않음). 소등 상호작용은 Flee 중 비활성 `[제안]` — 도망에 집중 |
| **풀포워드 규칙** | 플레이어가 `RedLightTime` 이전에 L1~L5 소등을 완료하면, 완료 시점 +30초(실시간)에 **강제 발동** `[제안]` — 빨간 불 이벤트는 반드시 1회 발생한다. 근거: §6 종료 게이트가 이벤트 소화를 요구하므로, 미발동 상태로 배전반 앞에서 무한 대기하는 상황을 차단 |

- `[확정]` 빨간 불은 밤당 정확히 1회. 추격체·이동체 없음 — 위협은 광원과 사운드로만 (스코프 방어, 기둥 2)

## 7. 클리어 시퀀스 · 엔딩 진입

```
배전반 E (게이트 충족)
 → [0.0s] 로그 `야간 조명 점검 종료 — 근무 기록 저장`
 → [1.0s] 박물관 전 조명 순차 소등 (배전실에서 소리로만 인지)
 → [3.0s] 페이드아웃 직전 컷: 어두워진 2층에 03:03 확인등 하나만 남아 있음 — 천천히 꺼진다. 로그: `근무자 확인 완료.` [확정 — GDD]
 → [6.0s] 페이드아웃 → 「Day 3」 카드 + RULE_FRAGMENT_02
 → 엔딩 시퀀스 로드 (RULE_FRAGMENT 3개 회수 — 연출 별도 기획 [확정 — GDD, 본 스펙 범위 외])
```

- 확인등 소등 컷은 카메라 강제 전환 1컷 `[제안]` (배전실에서 확인등은 보이지 않으므로) — 밤 전체에서 유일한 시점 이탈. `[팀 결정]` 1인칭 고수 시 대안: 소등을 사운드+로그로만 처리

## 11. QA 체크리스트

- [ ] L1~L5가 스케줄 시각에 점등되고 로그 형식이 확인등 포함 전부 동일하다
- [ ] 각 조명 `E` 소등 → 카운트 증가, 재점등된 L2 재소등 시 카운트 정합
- [ ] 재점등이 조건(밤 1회, L2, 02:00 이전, 15m 이탈) 밖에서 발생하지 않는다
- [ ] 확인등: 점등 후 1초 내 `E` → 무반응 / 이후 `E` → `근무자 미확인` + Failure / 조준 3초 → `광원 분석 불가` 1회
- [ ] 확인등이 백색이고 소등 카운트에 포함되지 않으며 05:00까지 유지된다
- [ ] 빨간 불이 120~270 (175~195 제외) 구간에서 추첨되고 밤당 1회만 발동한다
- [ ] 빨간 불 발동이 플레이어 위치·시야와 무관하고 로그 `비정상 점등 감지: 적색`이 뜬다
- [ ] 최원거리에서 달리기 도달 시간 < 40초 성립 (실측 후 TimeLimitSec 캘리브레이션)
- [ ] 제한 시간 40초 동안 어떤 UI에도 숫자·게이지가 표시되지 않는다
- [ ] 경비실 도달 → 3초 후 해제, 소등 진행 상태 보존 / 초과 → `S03_FleeTimeout` Failure
- [ ] 5개 소등을 빨간 불 이전에 끝내면 +30초 내 강제 발동한다 (풀포워드)
- [ ] Flee 중 소등·배전반 상호작용 비활성, 확인등 `E` 판정은 유지
- [ ] 배전반: 게이트 미충족 시 잔여 통지만 / 충족 시 클리어 시퀀스 1회 발동
- [ ] Failure·타임아웃 후 재시작 시 조명 초기화 + `RedLightTime` 재추첨 확인
- [ ] 클리어 컷에서 확인등이 마지막으로 꺼지고 「Day 3」 → 엔딩 시퀀스 진입
