# Rule Origins

## 목적

이 문서는 규칙별 출처, 원인 실패, 설계 의도, 통합 이력을 보관하는 장부입니다.

- 평소 작업에서는 읽지 않습니다. 규칙을 추가·수정·삭제하거나 재검증할 때만 참조합니다.
- 실제 행동 규칙은 각 담당 문서에 두고, 이 문서에는 출처와 변경 이유만 기록합니다.
- 기록 절차는 `docs/HARNESS.md`의 `규칙 추가 판단`을 따릅니다.

## 출처 유형

- `기획`: 제공된 Aeterna 시나리오 프로토콜에서 직접 나온 기준
- `이식`: 제공된 기존 하네스 문서에서 Aeterna에 맞게 이식한 기준
- `실패`: 실제 실패에서 나온 규칙
- `예방`: 실패 없이 예측으로 추가한 기준
- `설계`: 의도적 작업 환경 설계 결정
- `통합`: 여러 문서의 중복 규칙을 한 담당 문서로 모은 결정
- `기억 안 남`: 출처 미상이며 재검증 최우선 대상
