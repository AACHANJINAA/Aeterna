# 야간 시나리오 제작 프로토콜

## 목적

박물관 야간 경비 게임의 8개 시나리오를 같은 구조로 제작하기 위한 팀 공유용 프로토콜이다.

각 시나리오는 독립된 30분짜리 야간 업무로 구성하며, 모든 시나리오는 **경비실에서 시작하고 경비실에서 종료**한다.

---

## 전체 규칙

| 항목 | 내용 |
|---|---|
| 플레이 시점 | 1인칭 |
| 플레이어 | 야간 관리 로봇 M-05 |
| 전체 근무 시간 | 01:00 ~ 05:00 |
| 시나리오 개수 | 총 8개 |
| 시나리오 길이 | 각 30분 |
| 시작 지점 | 항상 경비실 |
| 종료 지점 | 항상 경비실 |
| 실패 처리 | 현재 시나리오 처음부터 재시작 |
| 실패 후 위치 | 경비실 |
| 실패 후 시간 | 해당 시나리오 시작 시각 |

## 공통 진행 흐름

| 단계 | 이름 | 위치 | 설명 |
|---|---|---|---|
| 1 | 시나리오 시작 | 경비실 | 정해진 시각이 되면 경비실에서 시나리오가 시작된다. |
| 2 | 업무 전달 | 경비실 | 무전, 수첩, 시스템 로그 중 하나로 업무가 전달된다. |
| 3 | 규칙 확인 | 경비실 | 수첩에 새 규칙이 표시된다. |
| 4 | 목표 구역 이동 | 시나리오별 구역 | 플레이어가 1인칭으로 목표 구역까지 이동한다. |
| 5 | 평범한 업무 수행 | 시나리오별 구역 | 순찰, 점검, 조명 확인, 전시물 확인 같은 업무를 수행한다. |
| 6 | 이상 현상 발생 | 시나리오별 구역 | 전시물, 조명, 소리, 그림자, 반사, 기록 등이 비정상 반응한다. |
| 7 | 규칙 기반 플레이 | 시나리오별 구역 | 플레이어가 수첩 규칙을 해석하고 지키며 목표를 완료한다. |
| 8 | 경비실 복귀 | 경비실 | 목표 완료 후 반드시 경비실로 돌아온다. |
| 9 | 시나리오 종료 | 경비실 | 클리어 처리, 체크포인트 저장, 다음 슬롯 대기 상태로 전환한다. |

## 실패 처리 규칙

조건 실패 시 전체 밤을 처음부터 되돌리지 않는다.

**현재 진행 중인 시나리오만 처음부터 다시 시작한다.**

### 실패 시 초기화되는 것

- 현재 시나리오 목표 진행도
- 현재 시나리오 전용 이상 현상 상태
- 현재 시나리오 전용 오브젝트 위치
- 현재 시나리오 전용 조명/전원 상태
- 현재 시나리오 경고 단계
- 현재 시나리오 중 획득한 임시 단서

### 실패해도 유지되는 것

- 이전 시나리오 클리어 기록
- 이전 시나리오에서 해금된 기본 기능
- 공통 플레이어 조작 설정
- 전체 게임 진행도

### 실패 후 흐름

1. 실패 연출 재생
2. 현재 시나리오 상태 초기화
3. 플레이어를 경비실로 이동
4. 게임 시간을 현재 시나리오 시작 시각으로 복구
5. 수첩 규칙과 업무 목표를 다시 표시
6. 같은 시나리오를 처음부터 재진행

## 시나리오 제작 템플릿

각 시나리오는 아래 항목을 반드시 작성한다.

| 항목 | 설명 |
|---|---|
| 시나리오 ID | S01 ~ S08 |
| 제목 | 시나리오 이름 |
| 작성자 | 기획자 이름 |
| 진행 시간 | 예: 01:00 ~ 01:30 |
| 시작 위치 | 경비실 고정 |
| 종료 위치 | 경비실 고정 |
| 주요 구역 | 중앙홀, 2층 복도, 자연사관 등 |
| 시작 트리거 | 무전 / 수첩 / 시스템 로그 / 환경 변화 |
| 평범한 업무 | 겉으로 보이는 야간 업무 |
| 수첩 규칙 | 플레이어가 지켜야 할 규칙 |
| 이상 현상 | 업무 중 발생하는 비정상 현상 |
| 클리어 조건 | 성공에 필요한 행동 |
| 실패 조건 | 롤백을 발생시키는 행동 |
| 클리어 연출 | 성공 시 보여줄 장면 |
| 실패 연출 | 실패 시 보여줄 장면 |
| 보상/단서 | 다음 시나리오나 엔딩에 연결되는 로그, 아이템, 기억 조각 |

---

## 수첩 규칙 작성 기준

각 시나리오에는 수첩 규칙을 3~5개 정도 넣는다.

### 반드시 포함할 것

- 실제로 지켜야 하는 생존 규칙
- 플레이어 행동을 제한하는 규칙
- 해석이 필요한 모호한 규칙

### 선택적으로 포함할 것

- 거짓 규칙
- 모순 규칙
- 후반부 복선 규칙
- 다음 시나리오와 연결되는 규칙

---

## 업무 목표 작성 기준

겉으로는 평범한 야간 업무처럼 보여야 한다.

사용하기 좋은 업무 예시는 다음과 같다.

| 업무 유형 | 예시 |
|---|---|
| 순찰 | 체크포인트 스캔 |
| 전시물 점검 | 전시물 위치, 개수, 상태 확인 |
| 조명 점검 | 샹들리에, 벽등, 비상등 확인 |
| 전력 복구 | 배전반, 퓨즈, 차단기 조작 |
| 장비 점검 | 센서 박스, 감시 카메라, 단말기 재부팅 |
| 분실물 회수 | 사라진 전시물 조각 찾기 |
| 단서 확인 | UV 글씨, 반사, 그림자, 시스템 로그 스캔 |

## 시스템 기준

### ScenarioManager

현재 시간 슬롯에 맞는 시나리오를 로드하고 상태를 관리한다.

필요 기능:

- 시나리오 로드
- 시나리오 시작
- 시나리오 클리어
- 시나리오 실패
- 현재 시나리오 재시작
- 플레이어를 경비실로 이동

### GameClock

01:00부터 05:00까지 30분 단위 슬롯을 진행한다.

각 슬롯은 하나의 시나리오와 연결된다.

### NotebookRules

각 시나리오 시작 시 수첩에 해당 시나리오 규칙을 표시한다.

규칙은 플레이어가 직접 읽고 판단해야 하며, 화면 UI보다 수첩 중심으로 전달한다.

### FailureSystem

실패 조건을 감지하고 현재 시나리오를 처음부터 다시 시작한다.

실패 연출 방향:

- 전시물화
- 기록 오류
- 카메라 암전
- 시간 되감김
- 경비실 재기동

---

## 팀 작업 규칙

- 모든 시나리오는 경비실에서 시작한다.
- 모든 시나리오는 경비실에서 종료한다.
- 실패 시 현재 시나리오만 처음부터 다시 진행한다.
- 각 시나리오는 30분짜리 독립 슬롯으로 만든다.
- 시나리오의 겉 목표는 평범한 야간 업무여야 한다.
- 공포 요소는 수첩 규칙과 실제 상황의 충돌에서 발생해야 한다.
- 클리어 후 다음 시나리오로 넘어가기 전 경비실에서 짧은 정리 시간을 둔다.
- 시나리오별 특수 오브젝트는 해당 시나리오가 끝나면 초기화한다.
