# "야간 수칙" 시스템 구체화

장르의 핵심은 **"규칙을 읽는 재미 → 규칙을 지키는 긴장감 → 규칙이 틀렸거나 모순될 때의 공포"** 3단계

---

## 1. 핵심 루프

```
출근(22:00) → 수첩 확인 → 순찰 업무 수행 
→ 규칙 상황 발생 → 지키거나/어기거나 
→ 생존 시 퇴근(06:00) → 다음 날 밤, 새 규칙 페이지 해금
```

- 밤마다 UI 시계가 실시간으로 흐름 (1분 = 현실 5~10초 정도)
- **업무 자체는 평범함**: 순찰 체크포인트 찍기, 문 잠그기, 온습도 확인 — 이 평범한 업무가 플레이어를 강제로 위험 지역에 보내는 장치가 됨. "23:30에 이집트관 순찰 체크를 해야 하는데, 규칙상 23:30엔 이집트관 동상을 보면 안 됨" 같은 충돌이 핵심 재미.

## 2. 전임 경비원의 수첩 — 규칙 예시

수첩은 낡고, 필체가 페이지마다 다르고(전임자가 여러 명이었다는 암시), 일부는 찢겨 있음.

**시간 규칙**
- 「23:30~23:33 사이에는 그리스관 병사 동상과 눈을 마주치지 마시오. *발소리가 들려도.*」
- 「01:00 정각에 로비 괘종시계가 13번 울리면, 즉시 가장 가까운 화장실에 들어가 문을 잠그고 세 번째 종소리… (이하 찢김)」
- 「03:33에는 어디에 있든 손전등을 꺼라. 빛을 *그것*이 봅니다.」→ 배터리 절약 규칙인 척하지만 사실 생존 규칙

**행동 규칙**
- 「해양관의 고래 뼈 아래를 지날 땐 숨을 참으시오. (게임에서 실제로 우클릭 홀드로 숨 참기)」
- 「누군가 "경비원님"이라고 부르면 대답하지 마시오. 진짜 동료는 당신 이름을 부릅니다.」
- 「엘리베이터는 절대 타지 마시오. 계단만 이용. 단, 4시 이후에는 계단도 안 됨.」→ 그럼 뭘 타야 하는지는 안 적혀 있음 (플레이어가 스스로 알아내야 하는 공백)
- 「전시물 개수를 세지 마시오. 세는 순간 숫자가 맞지 않는다는 걸 알게 됩니다.」

**모순/거짓 규칙 (후반 트위스트)**
- 어느 날부터 수첩에 **필체가 다른 새 페이지**가 끼어 있음: 「미라관에 들어와도 안전합니다. 오히려 이곳이 제일 안전해요.」— 기존 규칙과 정면 충돌. 어느 쪽이 진짜 전임자인가?
- 이게 나폴리탄 괴담의 백미라서, **"규칙을 검증하는 방법"** 자체를 콘텐츠로 만들면 좋아요. 예: 진짜 전임자의 필체는 항상 특정 잉크색 / 페이지 귀퉁이에 작은 표식.

## 3. 손전등 & 빛 시스템

**배터리 = 이 게임의 유일한 자원이자 화폐 감각**

- 배터리는 순찰 중 사무실 서랍, 자판기(동전 필요), 분실물 보관함에서 파밍
- 손전등 밝기 3단계: 약(배터리 절약) / 강(멀리 봄) / **UV 모드**(숨겨진 글씨·발자국 보임, 소모 3배)
- 어떤 존재는 빛에 멈추고, 어떤 존재는 **빛에 끌림** → 수첩 규칙으로 힌트를 주고, 플레이어가 상황마다 켤지 끌지 판단하게

**"퀘스트를 깨면 밝아진다"는 아이디어 → 두꺼비집 시스템으로 구체화:**

- 박물관의 구역별 배전반이 내려가 있음. 밤 업무 중 하나가 "발전기 수리" / "퓨즈 찾아 끼우기"
- 구역 전원을 복구하면 해당 관에 **상시 비상등**이 켜짐 = 그 구역에선 손전등 없이 이동 가능 + 특정 규칙이 비활성화됨 (「어둠 속에서만 움직이는 것」이 못 움직임)
- 단, 트레이드오프: **불이 켜진 구역은 "그들"도 당신을 잘 봄**. 밝음 = 무조건 안전이 아니라, 규칙이 바뀌는 것. 이러면 전원 복구가 단순 업그레이드가 아니라 전략 선택이 됨.

## 4. UI 디자인 (다이어제틱하게)

| 요소 | 구현 |
|---|---|
| 시계 | 화면 UI가 아니라 **손목시계를 들어 올려 확인** (확인하는 동안 시야 가림 = 리스크) |
| 수첩 | 인벤토리 아님. 실제 3D 수첩을 꺼내 페이지 넘김. 어두우면 손전등 비춰야 읽힘 |
| 체력/정신력 | 숫자 없음. 심장 소리, 호흡, 화면 가장자리 비네팅으로 표현 |
| 무전기 | 가끔 "본부"에서 지시가 옴. 그런데 03:00 이후의 무전은…? (수첩: 「새벽 3시 이후 무전에 응답하지 마시오」) |

## 5. 시간표 예시 — 첫째 밤

| 시각 | 업무 | 숨은 규칙 충돌 |
|---|---|---|
| 22:00 | 출근, 인수인계 쪽지 수령 | — |
| 22:30 | 1층 순찰 체크 4곳 | 튜토리얼, 안전 |
| 23:30 | 2층 그리스관 체크 | ⚠️ 동상 응시 금지 시간과 겹침 — 바닥만 보고 걷기 |
| 00:15 | 온습도계 기록 | 기록지에 어제 날짜 필체가 내 필체와 똑같음 (복선) |
| 01:00 | 괘종시계 태엽 감기 | 종이 13번 울리면? |
| 03:33 | (업무 없음) | 손전등 끄기 규칙 발동 — 암전 속 30초 버티기 |
| 06:00 | 퇴근 | 해가 뜨며 모든 게 제자리. 정말 제자리일까? |

## 6. 스토리 뼈대 제안

- 6일차 밤(6일 근무 = 6챕터), 매일 규칙이 1~2개씩 추가되고 기존 규칙이 변형됨
- 진엔딩 조건: 수첩 곳곳의 찢긴 페이지 조각을 모아 **"최후의 규칙"** 을 완성하는 것 — 예: 「이 수첩을 다음 경비원에게 물려주지 마시오. 수첩이 곧 계약입니다.」
- 멀티 엔딩: ① 규칙을 전부 지키고 퇴사(평범 엔딩) ② 최후의 규칙을 알고 수첩을 불태움(진엔딩) ③ 수첩에 자기 규칙을 새로 적음(당신이 다음 괴담의 작성자가 되는 엔딩)
